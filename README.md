# Quizly – Software System Analysis & Architecture Design

A comprehensive system specification and software architecture design project for **Quizly**, an interactive online testing and assessment platform. Designed using the **Model-View-Controller (MVC)** architectural pattern, focusing on scalability, user experience, and system reliability.

## Project Overview
Quizly is designed to streamline the creation, management, and grading of digital exams and quizzes for educators and students. This repository contains the full engineering documentation, requirement specifications, and UML architectural diagrams produced during the system design phase.

## Key Architectural Highlights
* **Architectural Pattern:** Structured around the **MVC (Model-View-Controller)** pattern to ensure clean separation of concerns between data management, business logic, and user interface.
* **Requirements Engineering:** Defined comprehensive **Functional Requirements** (user roles, quiz creation, automated grading, real-time exam execution) and **Non-Functional Requirements** (performance, security, usability, and availability).
* **UML Modeling:** Full behavioral and structural modeling including Use Case Diagrams, Class Diagrams, Sequence Diagrams, and Activity Diagrams.

## Repository Contents
* `Quizly_SRS.pdf` – Software Requirements Specification document (Functional & Non-Functional requirements, system constraints, and user stories).
* `Quizly_UML_Architecture.pdf` – Complete presentation of the system architecture and UML diagrams.
